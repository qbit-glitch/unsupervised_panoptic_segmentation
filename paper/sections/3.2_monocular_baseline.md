# 3.2 Monocular Pseudo-Label Baseline

Stereo and scene flow give CUPS access to physical-separation cues at pseudo-label time: a 3-D boundary between two adjacent surfaces produces a discontinuity in disparity or in inter-frame motion that separates one instance from another. Monocular depth exposes many of the same physical-separation cues in a single frame, provided that the discontinuity is read at the right spatial scale and only within a region whose semantic identity has already been settled. The Stage-1 generator $G$ from Eq. 1 is built around this observation: a frozen semantic branch produces $\hat S_x$, an instance branch produces $\hat I_x$ from depth-gradient cuts taken inside thing-eligible semantic regions, and the resulting pair is passed to panoptic bootstrapping.

The semantic branch is assembled entirely from frozen priors so that the boundary signal it supplies to the instance branch is reproducible across frames. Each image $x$ is encoded by a frozen DINOv2 ViT-B/14 backbone [Oquab et al., 2024], whose dense patch features are then reduced by a frozen CAUSE-TR head [Kim et al., 2024] to a 90-dimensional semantic code. We L2-normalize these codes (so that centroid distance is scale-invariant to feature magnitude) and partition them with k-means on the unlabeled training set into $k = 80$ centroids, assigning each pixel the index of its nearest centroid to obtain $\hat S_x$. The cardinality $k = 80$ is deliberately well above the 19-class evaluation taxonomy: collapsing to 19 classes at this stage would erase fine visual modes that the depth-based instance branch later relies on, such as occluded versus unoccluded vehicles. CUPS reports that this regime monotonically improves panoptic quality as $k$ exceeds the evaluation cardinality [Hahn et al., 2025, Tab. 7b]. We cluster the CAUSE-TR code rather than the raw 768-dimensional DINOv2 feature because CAUSE-TR has already organized the manifold into a concept-coherent partition; clustering on the raw feature would re-mix appearance modes that the unsupervised code has already factored out.

With $\hat S_x$ in hand, the instance branch reads physical-separation structure from a single monocular depth map $D \in \mathbb{R}^{H \times W}$. For the trained-network results reported in the main experiments we use a frozen DepthPro network [Bochkovskii et al., 2024], chosen because it balances boundary sharpness, which the gradient operator below requires, against surface smoothness, which keeps the interior of a single object connected. We apply $3 \times 3$ Sobel kernels $K_x, K_y$ to $D$ and form the per-pixel gradient magnitude $\|\nabla D(p)\| = \sqrt{(K_x * D)^2(p) + (K_y * D)^2(p)}$, since a physical 3-D boundary projects to a depth discontinuity that classical gradient operators are designed to localize. Pixels with $\|\nabla D(p)\| > \tau_d = 0.20$ are flagged as candidate boundaries; the threshold is chosen to keep depth-derived instances large enough for panoptic bootstrapping. A standalone-optimum threshold of $\tau_d = 0.01$ produces sharper instance proposals on the depth-only evaluation but over-fragments the training data (~57 instances per image, more than half below 1000 pixels), which the §4 ablation shows degrades trained-network PQ; the value $\tau_d = 0.20$ is used throughout the rest of the paper. Connected-component labelling with 8-neighbour adjacency (suitable for the diagonal boundaries that depth gradients produce at oblique surfaces) is then run only inside thing-eligible semantic regions. Each of the 80 over-clusters is assigned to its nearest concept in the CAUSE 27-class vocabulary by centroid distance in the 90-dimensional code space, and thing-eligibility is read off the CAUSE taxonomy, which fixes a thing/stuff partition over its 27 concepts at the head's training time (eight countable categories: car, truck, bus, train, motorcycle, bicycle, person, rider). Both the over-cluster fitting and the CAUSE taxonomy are obtained without target annotations; the Hungarian map between the CAUSE 27-class vocabulary and the Cityscapes 19-class evaluation taxonomy is computed only at evaluation time and is the only ground-truth-derived component anywhere in the pipeline. This restriction is important because depth gradients fire not only at object boundaries but also at intra-object material seams such as the hood-windshield transition on a car, and confining components to the interior of a single semantic region lets the semantic cue absorb such intra-class splits while still permitting depth to separate adjacent same-class objects. Components below $A_\text{min} = 1000$ pixels are discarded as residual depth artifacts unlikely to form reliable training targets at our working resolution, and the surviving components are dilated with three iterations of a $3 \times 3$ structuring element, which partially restores boundary pixels removed by thresholding without aggressively merging adjacent components.

Composing the two branches yields the baseline pseudo-label pair $(\hat S_x, \hat I_x)$, which is the monocular-depth baseline instantiation of $G$ from Eq. 1 and the input to panoptic bootstrapping. Because the fitted generator is applied deterministically to each frame, the failure modes of this baseline are also localized: the depth-driven instance branch behaves correctly wherever a 3-D surface change is visible, but the semantic regions inherited from the frozen CAUSE-TR code are appearance-driven and can split a single physical surface across an illumination change, such as sun and shade on the same road, or merge two adjacent same-class objects whose appearance differs only in fine geometry. Closing this gap requires conditioning the semantic code on the same depth signal that already governs the instance branch, which motivates the Depth-Conditioned Feature Adapter introduced in §3.3.
