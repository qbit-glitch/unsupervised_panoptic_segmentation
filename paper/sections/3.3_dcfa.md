# 3.3 Depth-Conditioned Feature Adapter

The semantic regions inherited from the frozen CAUSE-TR code are appearance-driven, and §3.2 closed by naming the two failure modes this produces inside $G$: a single physical surface is split across an illumination change, such as sun and shade on the same road, and two adjacent same-class objects whose appearance differs only in fine geometry are merged into one. Both expose cases where the depth signal that already governs the instance branch can disambiguate appearance-driven semantic errors, but only if the semantic code can be conditioned on $D$ without retraining the backbone that the rest of the pipeline depends on. We therefore introduce a small residual adapter that consumes the depth value $d_u$ at pixel $u$ and adds a learned depth-driven shift to the frozen 90-dimensional code $z_u$, nudging cluster boundaries toward depth-consistent regions where appearance fails, while preserving the unsupervised prior elsewhere.

Conditioning on $d_u$ requires a representation rich enough for a small MLP to read both fine boundary differences and coarse depth ordering. Since $d_u \in [0, 1]$ is a scalar with low dynamic range, we lift it through a 16-dimensional sinusoidal positional encoding with eight exponentially-spaced frequencies $\omega_k = 2^k \pi$ for $k = 0, \dots, 7$,

$$
e(d_u) = \big[\sin(\omega_0 d_u),\, \cos(\omega_0 d_u),\, \ldots,\, \sin(\omega_7 d_u),\, \cos(\omega_7 d_u)\big] \in \mathbb{R}^{16},
\tag{2}
$$

so that the high-frequency channels make boundary-scale depth differences linearly readable while the low-frequency channels expose foreground-versus-background ordering. This mirrors the role of positional encodings in transformers, applied to a one-dimensional metric input rather than to a sequence position.

The encoding $e(d_u)$ is then passed through a two-layer MLP $r: \mathbb{R}^{16} \to \mathbb{R}^{90}$ with hidden width $h = 384$ (a width chosen to give the residual enough capacity at the 90-dimensional output), ReLU activation, and a zero-initialized output projection. The MLP produces a depth-only shift that is added residually to the frozen code,

$$
\tilde z_u = z_u + r\big(e(d_u)\big),
\tag{3}
$$

so that depth modulates the frozen semantic code through an additive residual. The construction has approximately 40K trainable parameters, small relative to the roughly 86M parameters of the frozen ViT backbone, so the adapter acts as a calibration on the prior rather than a re-training of it. Two properties of this construction matter for the rest of the pipeline. Because the output projection is zero-initialized, $\tilde z_u = z_u$ at the first optimizer step, so the adapter cannot degrade the frozen prior before any depth signal has been read. And because the DINOv2 backbone and CAUSE-TR head are kept frozen, the same $\tilde z_u$ remains usable by the k-means partition of §3.2 and by the feature-similarity cue used in SIMCF (§3.4).

Training the adapter calls for a self-supervised signal that pulls the adapted codes of pixels at similar depth toward each other while keeping them on the original CAUSE-TR manifold. DepthG [Sick et al., 2024] established that depth-feature correlation can guide unsupervised semantic learning when depth governs the loss, and we reuse the same loss at the adapter level rather than to the backbone weights. For each minibatch image, we sample 1024 pixels and 1024 pixel pairs, using the DepthG depth-similarity kernel with bandwidth $\sigma_d = 0.5$. The adapter minimizes $\mathcal{L}_\text{DCFA}=\mathcal{L}_\text{corr}+\lambda_\text{preserve}\mathcal{L}_\text{preserve}$, where $\mathcal{L}_\text{corr}$ is the DepthG correlation loss on $(\tilde z,D)$, $\mathcal{L}_\text{preserve}$ is the mean squared distance between $\tilde z$ and $z$, and $\lambda_\text{preserve}=20$. The correlation term encourages pixels on the same physical surface to remain clustered even when appearance changes, while the preservation term prevents collapse in regions where depth alone is uninformative. This contrasts with DepthG, which injects the depth-correlation signal into the backbone's training loop and modifies the ViT weights end-to-end. Freezing the backbone keeps the prior reusable across §3.2's clustering and §3.4's similarity cue, which is the property we exploit downstream.

Even with depth-conditioned semantic codes, the pseudo-label pair $(\hat S_x, \hat I_x)$ can still disagree at the output level. A depth fragment may straddle the hood-windshield seam of a car despite a coherent semantic region, and a pixel may take a depth value far from the per-class statistics of the class it has been assigned. SIMCF (§3.4) addresses these output-level disagreements through a label filter that requires three complementary cues: semantic identity, instance geometry, and feature similarity, to agree before a candidate label is accepted.
