# 2026-03-30 — Novel Semantic Ablation Complete

## Completed

### Novel COCO Semantic Pseudo-Label Ablation (3 approaches)
Ablated 3 novel approaches to improve COCO-Stuff-27 semantic pseudo-labels beyond k-means overclustering.

**Approach 1: Spectral Enrichment** — Per-image graph Laplacian eigenvectors appended to DINOv3 features. Best config: +1.9% over k-means at K=300 (28.6% vs 26.7%). Doesn't scale with K. Hierarchical merge kills performance.

**Approach 2: SAM Superpixel Consensus** — SAM ViT-B segments as superpixels, pool DINOv3 features per segment, global k-means. **Best overall: SAM K=1000 = 34.4% mIoU** (+2.5% over plain k-means). Consistent improvement at all K values.

**Approach 3: Matryoshka Self-Distillation** — SwAV-style EMA teacher with Sinkhorn-Knopp. Failed (2.0% mIoU) — confirms all learned methods need real image augmentation.

36 configurations evaluated via unified evaluation script on 501 val images.

### Key Takeaways
- Overclustering remains the biggest lever (K=300 to K=3000 = +11.2%)
- SAM boundaries are the best secondary improvement (+1.6 to +2.7%)
- No learned method works on pre-extracted features
